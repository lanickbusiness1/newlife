# AfrIAgenesis® Startup Accelerator Genome™

Application statique de diagnostic d'éligibilité et d'evidence readiness pour accélérateurs, concours d'innovation et programmes de scale-up.

## Fonctions livrées

- scoring sur 100 ;
- critères éliminatoires ;
- niveaux de preuve P0 à P3 ;
- gates G1 à G8 ;
- recommandations automatiques ;
- export d'un Executive Eligibility Memo ;
- interface responsive sans dépendance externe.

## Exécution

Ouvrir `index.html` dans un navigateur ou servir le dossier avec n'importe quel serveur statique.

## Gouvernance

Identifiant canonique : `GENOME-STARTUP-ACCELERATOR-001`.
Toute soumission demeure soumise à une validation humaine et aux contrôles M6, S7+ et M8.
