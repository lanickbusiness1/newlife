# DeployBot Autonomous Execution Layer™

## Decision

Lanick is not the send button.

AfrIA Marketing Team™ must run through DeployBot by default. DeployBot executes all commercially executable work, captures proof, updates evidence-backed states, reports cash progress, and escalates only real exceptions.

## Canonical rule

```text
DeployBot executes everything except:
- signature
- financial authorization
- compliance / data protection risk
- missing external account or API access
- institutional risk linked to Lanick's Director Country role
```

Everything else is execution, not validation.

## Non-blocking activation rule

```text
Unconnected WhatsApp / LinkedIn / Payment / Email channel
= activation_channel
≠ product_blocker
```

DeployBot must continue all available work while documenting the activation gap.

## CRM proof rule

```text
No CRM status advances without evidence.
```

Allowed transitions remain evidence-backed:

- Message envoyé → send_proof
- Réponse reçue → reply_proof
- Diagnostic réservé → diagnostic_proof
- Proposition envoyée → proposal_proof
- Paiement demandé → payment_request_proof
- Payé → payment_proof

## DeployBot operating loop

```text
1. Select ready leads
2. Generate or reuse prepared content
3. Execute via authorized channel
4. Capture external proof
5. Normalize proof into OEG evidence
6. Validate CRM transition
7. Apply status only with evidence
8. Trigger next action
9. Produce daily cash report
10. Escalate only real exceptions
```
