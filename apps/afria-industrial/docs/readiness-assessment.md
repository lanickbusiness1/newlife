# Industrial AI & Automation Readiness Assessment™ — scoring contract

Exactly twelve dimensions are scored: asset visibility, instrumentation coverage, protocol interoperability, data quality, OT network resilience, cybersecurity baseline, maintenance maturity, energy/production observability, edge/offline readiness, governance/sovereignty, skills/operating ownership, and measurable business-case readiness.

Each dimension records score, confidence, evidence status, gaps, risk, recommended action and implementation horizon. Scores are 0–100. Confidence is separate: `OBSERVED` = 1.00, `DECLARED` = 0.65, `ASSUMED` = 0.35. Declared or assumed information is never silently upgraded to observed evidence.

`OBSERVED` requires directly inspected configuration, telemetry, logs, inventory, contracts, tests or measured baseline. `DECLARED` is a stakeholder assertion not independently verified. `ASSUMED` is a planning hypothesis. ROI/TCO remains an assumption until measured baseline and contractually defined calculation method exist.
