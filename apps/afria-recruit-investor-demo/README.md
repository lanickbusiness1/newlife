# AfrIA Recruit™ Investor Demo

Frontend investisseur connecté au projet Supabase réel `afria-recruit`.

## Objectif

Démontrer un parcours vérifiable :

1. cockpit exécutif ;
2. vivier candidats ;
3. besoins institutionnels ;
4. matching explicable ;
5. consentement et revue humaine ;
6. pipeline commercial et revenus.

## Variables

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

## Contrôles de release

- build obligatoire ;
- aucune clé secrète dans le dépôt ;
- données investisseur explicitement marquées `DEMO` ;
- décisions IA soumises à revue humaine ;
- déploiement public interdit tant que les contrôles M6/S7+/M8 ne sont pas renseignés.
