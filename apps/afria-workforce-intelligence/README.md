# AfrIA Workforce Intelligence™ — RC1

Entreprise RH vivante rattachée à GENOME™ et opérée sous constitution GENESIS V4.

## Exécution

Ouvrir `index.html` via un serveur HTTP statique. Le service worker active le mode hors ligne après la première visite.

## Fonctions livrées

- cockpit exécutif interactif ;
- objets employés et onboarding démonstratif ;
- présence, congés et anomalies ;
- World Model RH à six couches ;
- simulation de scénario avec coût, impact humain, conformité et confiance ;
- Agent Registry avec autonomie graduée ;
- Enterprise Control & Assurance ;
- Mission Control M6, S7+, M8 et Big4-ready ;
- PWA responsive et offline-first.

## Garde-fous

- aucune sanction, suppression de poste, modification salariale ou décision sensible automatique ;
- validation humaine obligatoire ;
- séparation initiateur / approbateur / exécuteur / contrôleur ;
- preuves d'exécution et audit trail ;
- rollback et arrêt d'urgence prévus par la constitution.

## Statut de preuve

Cette RC1 est un démonstrateur fonctionnel frontend avec données de démonstration. Elle ne prétend pas encore fournir un backend transactionnel, une authentification production, une paie réelle ou une conformité juridique certifiée.

## Prochaine promotion

RC2 : API, PostgreSQL/Supabase, IAM multi-tenant, RLS, Evidence Vault persistant, workflows d'approbation, tests automatisés et déploiement contrôlé.
